# LouDS — Marca personal

Presentación web interactiva realizada con HTML, CSS y JavaScript sin dependencias de instalación.

# Objetivos

1. Presentar la marca personal LouDS que fue creada por Pelozo Aranda Lourdes Silvina, durante la carrera en curso de Desarrollo de Software y en la materia de Cultura y Comunicación de 2° año.

2. Demostrar las diferentes competencias con que cuenta la marca y su presentadora, ya que ambas conforman y engloban una unidad productiva y resolutiva en el área socio-tecnológico mediante la resolución de problemas con soporte técnico-digital.

## Archivos

- `index.html`: entrada inicial, redirige a la presentación.
- `LouDS — Marca personal.html`: contenido de las diapositivas.
- `styles.css`: estilos, tipografía y fondos.
- `script.js`: navegación, notas del presentador y pantalla completa.
- `README.md`: instrucciones de uso y publicación.

## Uso

Abrir `index.html` en un navegador. Se requiere conexión a Internet para cargar Roboto desde Google Fonts; sin conexión se utilizarán fuentes alternativas.

### Controles

- `←` / `↑`: diapositiva anterior.
- `→` / `↓` / `Espacio`: diapositiva siguiente.
- `N`: mostrar u ocultar las notas del presentador.
- `F`: activar o salir de pantalla completa.
- También se puede avanzar o retroceder haciendo clic en los lados derecho o izquierdo.
